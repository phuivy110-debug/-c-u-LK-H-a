D. CẤU TRÚC DỮ LIỆU SẢN PHẨM HIỆN TẠI
--------------------------------------------------------------------------------
Mỗi sản phẩm có 17 trường chuẩn bao gồm:
- id: string (VD: 'lk-001' hoặc 'sheet-1')
- title: string (Tên sản phẩm)
- category: CategoryId ('rods' | 'reels' | 'lines' | 'baits' | 'floats' | 'accessories')
- originalPrice: number (Giá gốc VNĐ)
- dealPrice: number (Giá ưu đãi VNĐ)
- discountPercent: number (% Giảm giá)
- image: string (URL hình ảnh)
- badges: BadgeType[] ('Deal hot' | 'Bán chạy' | 'Giảm sâu' | 'Shopee Mall')
- affiliateUrl: string (Link Affiliate Shopee Mall)
- tiktokUrl: string (Link Affiliate TikTok Shop Official)
- shopName: string (Tên shop)
- rating: number (Đánh giá)
- soldCount: string (Số lượng đã bán)
- isMall: boolean (Cờ Shopee Mall)
- couponCode: string (Mã giảm giá độc quyền)
- description: string (Mô tả ngắn)
- updatedAt: string (Thời gian cập nhật)

* Trường còn thiếu: 'slug' (đường dẫn URL SEO) và 'isFeatured' (cờ sản phẩm nổi bật).
