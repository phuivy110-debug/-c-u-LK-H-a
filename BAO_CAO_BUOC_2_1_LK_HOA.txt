2. HẠNG MỤC CẢI TIẾN CHI TIẾT VÀ TẬP TIN XỬ LÝ
--------------------------------------------------------------------------------

[1] Cấu trúc Dữ liệu & Types (`/src/types.ts`)
    - Loại bỏ các trường ảo không dùng trong Google Sheet (badges, rating, soldCount,
      couponCode, isMall, shopName).
    - Thống nhất Schema `Product`:
      * id: string
      * slug: string (chuẩn SEO)
      * name: string
      * category: string (tên danh mục thực tế từ Google Sheet)
      * price: number
      * originalPrice: number
      * imageUrl: string
      * shopeeUrl: string
      * tiktokUrl: string

[2] Đồng bộ Google Sheet (`/src/utils/googleSheetSync.ts`)
    - Xử lý slug tự động: Tạo slug tiếng Việt không dấu chuẩn SEO (VD: `can-cau-tay-lk-hoa-6h`).
      Tự động thêm suffix phân biệt nếu trùng tên.
    - Xử lý giá tiền: Hàm `parsePriceNumber()` lọc bỏ toàn bộ ký tự phi số (đ, ., ,),
      đưa giá bán và giá gốc về định dạng số nguyên chuẩn VNĐ.
    - Trích xuất ảnh tự động: Trường hợp thiếu link ảnh trực tiếp, hệ thống tự động
      trích xuất hình ảnh chất lượng cao từ link Shopee sản phẩm.
    - Chuẩn hóa danh mục: Tự động gom nhóm danh mục thực từ cột Google Sheet, mặc định
      `Chưa phân loại` nếu bị trống.

[3] Xác thực Link Affiliate (`/src/components/AffiliateButtons.tsx`)
    - Tích hợp hàm `validateAffiliateUrl()` kiểm tra hostname nghiêm ngặt:
      * Shopee: shopee.vn, s.shopee.vn, shope.ee, shopee.com, vn.shopee.asia.
      * TikTok: tiktok.com, vt.tiktok.com, shop.tiktok.com, m.tiktok.com.
    - Gắn thẻ <a> chuẩn SEO & An toàn:
      `target="_blank" rel="sponsored nofollow noopener noreferrer"`

[4] Đồng bộ Giao diện Component
    - `/src/components/ProductCard.tsx`: Hiển thị nhãn danh mục thực, tính % giảm giá
      chính xác (`originalPrice > price`), dùng component AffiliateButtons chung.
    - `/src/components/ProductDetailModal.tsx`: Hiển thị đầy đủ thông tin chi tiết
      sản phẩm thực, gợi ý sản phẩm cùng danh mục từ Google Sheet.
    - `/src/components/CategoryFilter.tsx`: Hiển thị thanh tab danh mục động được
      tạo từ Google Sheet kèm số lượng sản phẩm tương ứng.
    - `/src/components/ChatBot.tsx` & `/api/chat.ts`: Cập nhật Trợ lý AI LK Hòa
      sử dụng dữ liệu sản phẩm thực tế từ Google Sheet để tư vấn và cung cấp link mua hàng.
    - `/src/data/products.ts`: Xóa toàn bộ sản phẩm giả lập ban đầu.

[5] Loại bỏ Số liệu Giả trong Analytics (`/server.ts`)

    - Hệ thống ghi nhận 100% dữ liệu người dùng thực tế.

3. QUY TẮC MAPPING CỘT GOOGLE SHEET
--------------------------------------------------------------------------------
- ID sản phẩm         => Mã SP, ID, Mã (Tự sinh ID dạng prod-[slug] nếu trống)
- Tên sản phẩm        => Tên sản phẩm, Tên, Name, Title
- Danh mục sản phẩm   => Hạng mục, Category, Danh mục, Loại, Nhóm

- Giá niêm yết        => Giá gốc, Original Price, Niêm yết
- Link Shopee         => Link Shopee, Shopee URL, Link Affiliate Shopee
- Link TikTok         => Link TikTok, TikTok URL, Link TikTok Shop
- Link Hình ảnh       => Link ảnh, Ảnh sản phẩm, Image URL, Image (Tự extract nếu trống)
